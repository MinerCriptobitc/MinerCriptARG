Cómo recibir pagos y minar correctamente

Necesitas una wallet compatible con la moneda que minas para recibir los pagos. Para Bitcoin (BTC) recomendamos:

  • 💻 Wallet Electrum
  • 👛 Hardware wallets recomendadas para grandes cantidades

Ejemplo completo (minería de Ethereum Classic - ETC):

  1. 🖥️ Equipo recomendado:
    • 6 × NVIDIA RTX 3060 Ti
    • Motherboard compatible
    • PSU de 1200W
    • Rig frame y ventiladores
  2. 🪙 Pool de minería: Ethermine, 2Miners, etc.
  3. 👛 Wallet para recibir ETC: MetaMask configurado para la red Ethereum Classic
  4. 🧠 Configura tu software de minado: T-rex, TeamRedMiner o NBMiner con tu dirección de wallet y pool

Tips importantes:

  • ✔ Calcula costo de luz antes de minar: la minería consume mucha energía.
  • ✔ Usa siempre wallets seguros (ideal hardware wallets para grandes cantidades).
  • ✔ Elige moneda rentable según mercado y dificultad.
